# 🎮 Quiz & Multi Mini-Game Challenge

A web application that combines general knowledge quiz questions with classic interactive mini-games. For every question answered, players unlock a unique mini-game challenge to test logic, spatial awareness, memory, and reaction speed.

---

## 🌟 Features

* **Interactive Quiz Mechanics:** Multiple-choice questions across diverse categories.
* **4 Distinct Mini-Games:**
  * **🧩 4x4 Mini Sudoku:** Fill the grid so numbers 1–4 appear once per row, column, and 2x2 box.
  * **🖼️ 3x3 Sliding Tile Puzzle:** Slide numbered tiles into sequential order (1 to 8).
  * **🃏 Memory Card Match:** Find all matching pairs from a shuffled 8-card grid.
  * **⚡ Reaction Speed Test:** Test your reaction time by clicking as fast as possible when the target turns green.
* **Score Tracking:** Earn points for correct quiz answers and successfully completed mini-games.
* **Zero Dependencies:** Built entirely with standard HTML5, CSS3, and Vanilla JavaScript—no external libraries or frameworks required.
* **GitHub Pages Ready:** Structured for effortless deployment via GitHub Pages using a single `index.html` file.

---

## 🕹️ How to Play

1. **Answer the Question:** Choose your answer for the multiple-choice quiz prompt (+100 pts).
2. **Complete the Mini-Game:** Answering unlocks a mini-game challenge related to the round.
3. **Earn Bonus Points:** Complete the mini-game challenge correctly to earn extra points (+50 pts).
4. **Advance & Finish:** Work through all 4 rounds to view your total score on the final leaderboard screen!

---

## 🚀 Quick Start / Local Setup

1. **Clone or Download:** Download the repository files to your local device.
2. **Open `index.html`:** Double-click the `index.html` file or drag it into any modern web browser (Chrome, Firefox, Safari, Edge).
3. **Play Instantly:** No installation, node servers, or build commands required!
